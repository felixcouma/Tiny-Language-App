## Architecture
- `src/store.js` — Zustand store: screen router, **profiles** (per-child progress in localStorage; **generic renamable children** — fresh devices seed only "Everyone" then ask **"how many children?"** at setup; `childCount` 1|2 gates Twin Mode; the original device keeps its AJ/AG twins via migration), `stage`, `progress` (`seen`/`lastSeen`/`byWorld`/`collected` + `daily` bucket for the parent-facing "today" line, auto-resets on date rollover; + `week` rolling-7-day bucket → the "This week with Pip" narrative via `weeklyFavWorld()`), per-child `focusWords` + **`enabledSongs`** + **`expectantPause`** (Learning-screen "Wait time"), gate + screen-time, and **cloud** state (`session`/`account`/`cloudStatus` — see Part B). New per-child settings must be added to the seeds + `loadProfiles()` migration + `cloud.js` settings so they sync.
- `src/data/content.js` — 7 worlds / 140 items (`word`, `wiki`, `say`, `soundLabel`, `expand` ladder, `sound` key); also exports `PRAISE` (rotating correct-answer praise).
- `src/data/phraseContent.js` — speech-therapy vocab: **266 core words** (frequency tiers / categories), `PHRASES` (2-/3-word banks), **`CORE_BOARD`** (the Word Board's fixed AAC core page), `imageKeyFor`/`WORD_ALIAS` (image reuse), readiness helpers. Word Board fringe pages are all a **multiple of 4** (4-col grid).
- `src/data/songs.js` — "Sing with Pip" catalog: 13 public-domain children's songs (exact titles, vocab `tag`, card `grad`, `animated` flag) + `DEFAULT_SONG_IDS`. Audio in `public/sounds/songs/<id>.mp3`.
- `src/data/songAnimations.js` — per-song animation configs (poses / lyric lines / cue `seq` / timing) for every `animated` song; `build()` compiles them to an audio-time cue timeline. Rendered by `components/SongAnimation.jsx`; poses generated by `scripts/gen-song-poses.mjs --song <name>` (base pose drawn fresh, action poses anchor on it) → `song-<key>.webp`. Verify with `scripts/verify-song-anims.mjs`.
- `src/data/actionAnimations.js` — "Things I Do" **verb** animations, keyed by the item's `sound` (e.g. `do-jumping`). Unlike songs there's **no audio to sync** — `components/ActionAnimation.jsx` just loops the frames on a fixed interval (**hard cut, not a fade** — action silhouettes differ too much to fade cleanly). Plays on the big Learning stage only (game/grid cards use frame 0, via `ItemVisual`). Two characters: the Head/Shoulders **boy** (`song-ready`) + a **girl** anchor (`act-girl-ready`); solo verbs alternate boy/girl, social ones (hug/dance/laugh/play) show **both children**. Frames via `scripts/gen-action-poses.mjs` (anchor-conditioned, ~2/verb) → `act-*.webp`. Verify with `scripts/verify-actions.mjs`.
- `src/data/fxKeys.js` — shared `FX_KEYS` (animals with a real `public/sounds/fx/<key>.mp3`, the file bakes a 3–4× repeat). Imported by `audio.js` (`playFx`), the game screens, AND both clip scripts so they never drift. In the games, **fx-animals play the real recorded sound** in the prompt ("[trumpet] Where's the elephant?"); non-fx animals (butterfly/turtle/fish/snake) speak a short cue. `components/ChoiceGame.jsx` (shared listen-and-tap game) gives **labelled praise** ("You found the {word}!") + an **errorless retry ladder** (repeat → narrow to 2 → model the answer + accept, never a fail) and plays `playFx` before the spoken "Where's the …?".
- `src/lib/` — `audio.js` (playback order: chosen-voice clip → Aoede default clip → phrase clip → **soft chime; NEVER the device voice**; `voice()`/`voiceSeq()`/`sayWord()`/`playItem`/`playFx`), `images.js` (local WebP/png → Unsplash/Pexels → Wikimedia; cache key `tv_img_cache_v3`), `today.js` (adaptive session), `screentime.js` (per-child limit + quiet hours), `useWakeLock.js`, **`supabase.js`** (null-safe client; cloud is optional), **`cloud.js`** (Part B: magic-link auth + per-child cloud sync + trial; no-op when unconfigured).
- `src/data/routines.js` — **"Every Day with Pip"** routine scenes (Mealtime/Bedtime/Getting dressed/Bath/Park). Each step: `say` (narration clip) + a tap-along `tap` (word) with optional `anim` (a `do-*` verb animation) or `img` (scene/summary image override). A step can be `{ variants, pick }` for a random body part each play (the Bath "wash your ___"). `RoutineScreen.jsx` resolves variants per playthrough (tap-along + generous no-fail auto-advance; `verify-routines.mjs`). `routineSayLines()`/`routineTapWords()` feed the clip generator + orphan-cleaner.
- `src/data/gamePrompt.js` + `src/data/spokenPhrases.js` — **single sources of truth** (were mirrored copies). `gamePrompt.js` = the listening-game `findPrompt`/`gamePrompts`, imported by SoundGame/TwinMode **and** the clip scripts. `spokenPhrases.js` `spokenTexts()` = every string the app `voice()`s, imported by `gen-tts-gcloud` + `clean-orphan-clips` + `verify-audio-coverage`. Change a prompt/phrase in ONE place.
- `src/screens/` — Setup ("how many children?"), ProfilePicker, Home, Learning, Today, Collection, Parent, SoundGame/TwinMode/Phonics (all via `ChoiceGame`), **Phrase** (Word Practice / Phrase Builder), **Grid** (Word Board AAC + "Find" word-focus mode), **Routine** ("Every Day with Pip"), **Song** ("Sing with Pip" — a transport-bar player; `verify-song-player.mjs`), Chant, Rest. All screens except Home are **`React.lazy` code-split** in `App.jsx` (small initial JS); shared CSS must be global (see the guard note below). Page **refresh restores the current screen** (per-tab `sessionStorage` nav in `store.js`).
- `src/components/` — WordPic (picture, or a bold coloured word-tile when no image), TactileStage, Ladder, Mascot (Pip), Confetti, CollectToast, Onboarding, InstallHint, UpdatePrompt, ParentGate, ErrorBoundary.
- `public/images/<key>.webp`, `public/sounds/<voice>/<key>.mp3` (per-voice item clips) + `public/sounds/phrases/<slug>.mp3` (Aoede phrase clips) + `public/sounds/fx/<key>.mp3` (real animal sounds) + `public/sounds/songs/<id>.mp3` (full-length PD children's songs — runtime-cached, not precached).

## SaaS (Part B — optional, pilot)
TinyVoice is now a **therapist-driven pilot**: primary surface is **Vercel** (`tiny-language-app.vercel.app`, runs serverless + has the cloud env); GitHub Pages stays a free demo. Parents can **optionally** sign in (Supabase magic link) to back up + sync each child's progress/settings and run a **30-day soft-trial** (banner only — child play is never blocked). Stack: Supabase (auth + Postgres + RLS) — tables `accounts`/`children`/`progress`. Env (`.env.local`, gitignored; set in Vercel): `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `VITE_FEEDBACK_URL`. **Without** the Supabase vars the app runs fully local exactly as before. Stripe billing (Part C) is scoped but not built.

## Tooling & reviews
- **`tools/council/`** — a standalone "Agent Council" review tool (own `package.json`; Express + Anthropic SDK — kept OUT of the app's deps). `cd tools/council && npm install && npm start`. Its critiques are evaluated against the real code in **`docs/COUNCIL_REVIEW_RESPONSE.md`** (accept/reframe/decline) — treat council output as an outside-in view, not ground truth.
- Backlog lives in **`docs/LEFT_TO_DO.md`** (numbered items, done/open status). Verify UI changes headlessly with the `scripts/verify-*.mjs` Playwright checks (each asserts 0 console errors); `npm install playwright --no-save` first (asset-gen installs prune it). **`npm run verify:ui`** is the regression suite — it builds, serves `vite preview`, and runs the checks as one pass/fail gate. `verify-actions.mjs` tests a **device × reduced-motion matrix** (a Reduce-Motion freeze once shipped unnoticed because the old test only ran motion-ON — don't remove that dimension).
- **Silent-failure guards in `npm run check`** (each a `scripts/verify-*.mjs`, most caught a real latent bug): **css-scope** (a className used in one code-split screen but defined only in another's CSS chunk → unstyled; rule: shared class → `src/styles/global.css`, component class → its own imported CSS); **audio-coverage** (every phrase the app `voice()`s has a clip in `sounds/phrases/`, else a silent chime); **asset-integrity** (every animation frame / routine image / fx file exists); **settings-sync** (every cloud-synced per-child setting is in the child seed). `verify:ui` also runs **bundle-size** (entry chunk ≤ 85 KB gzip — guards the code-split perf win). The listening-game prompt + the full spoken-phrase set now each live in **one** shared module (`src/data/gamePrompt.js`, `src/data/spokenPhrases.js`) instead of mirrored copies — screens + gen-tts + clean-orphan all import them, so they can't drift.

## Conventions (golden rules)
- **No emoji, no synthetic placeholders** — real WebP illustrations + warm voice + real animal sounds.
- **No scores / streaks / pressure** — gentle collection + celebration only (reward curiosity).
- **Speech-first** — children HEAR every word in a warm pre-rendered voice (Aoede default · Leda · Sulafat). **No robotic device voice** — a missing clip plays a soft chime, so clip coverage must stay complete (e.g. letters A–Z, phonics prompts, praise all have clips).
- **Per-child** — progress, stage, screen-time, bedtime all live on the active profile.
- **Responsive** — phone design below 700px; widens for tablet/laptop. **Toddler-safe**, `prefers-reduced-motion` respected.
- Match the surrounding code style; keep changes lean.

## Gotchas
- **Service worker cache**: `registerType: 'autoUpdate'`; `/sounds/` + `/images/` use **StaleWhileRevalidate** with cache names `tv-sounds-v2` / `tv-images-v2` — so a re-recorded clip/image at the SAME url self-heals on the next play. If you ever need to force a global refresh, bump the `-v2` suffix in `vite.config.js`.
- **TTS via Vertex (Cloud TTS)**: Gemini-TTS has a **per-minute** quota — if a batch 429s, slow `PACE_MS` (1000–3500). The `input.prompt` (style) can bleed into the audio, so the generator sends **text only**. Detect a leaked/garbled clip by **oversized file** (a short clip ≥~65 KB has baked-in narration); regenerate just those with `--force`.
- **Deploy**: push to `main` → GitHub Action (`.github/workflows/deploy.yml`) builds + publishes to Pages. `dist/` is gitignored. Commit/push only when asked; this project deploys from `main`.
- **Game prompts live in 4 mirrored spots** — `buildPrompt` in `SoundGameScreen`/`TwinModeScreen`, and `gamePrompts` in `gen-tts-gcloud.mjs` + `clean-orphan-clips.mjs`. Change a prompt string in ALL FOUR (same string → the clip generates AND isn't pruned), then `gen-tts-gcloud.mjs --kind phrases` + `clean-orphan-clips.mjs --apply`. fx-animals now use a plain "Where's the X?" (the real sound plays separately); non-fx animals keep a spoken cue via the `CUE`/`PROMPT_CUE` maps.
- **Local dev automation (this machine):** `.githooks/post-commit` (committed; `core.hooksPath=.githooks`) auto-starts `npm run dev` after a commit when 5173 is down (idempotent, Windows-guarded, no-op in CI). The `TinyVoice-dev-idle-stop` Windows scheduled task (hourly) stops the dev server after 24h with no commit. Helper `scripts/dev-idle-stop.ps1` + its `.log` are gitignored.
